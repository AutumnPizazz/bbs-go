# 任务及成长体系移除计划

状态：实施中（后端核心已完成，前端清理与验证未完成）

更新时间：2026-07-20

## 1. 目标

当前项目的主要业务方向调整为：

- 话题
- 文章

完全移除任务及其成长体系，包括：

- 任务配置、任务进度、任务完成日志
- 每日签到
- 用户等级和经验
- 用户勋章/荣誉
- 积分、积分流水和积分排行榜
- 任务奖励和由成长体系触发的等级、勋章消息
- 问答悬赏及其积分扣除、返还、奖励机制
- 附件下载积分门槛及下载扣费机制

问答发布和附件下载改为完全自由，不再要求用户拥有积分，也不再产生积分流水。

## 2. 当前架构结论

任务系统的核心入口是 `TaskEngineService`。内容、互动和登录事件由事件总线发布，再由任务事件处理器累计任务进度并发放积分、经验和勋章。

主要代码位置：

- 后端模型：`internal/models/models.go`
- 任务引擎：`internal/services/task_engine_service.go`
- 任务事件订阅：`internal/services/eventhandler/task_event_handler.go`
- 任务/签到/勋章 API：`internal/handlers/api/`
- 后台管理 API：`internal/handlers/admin/`
- 任务相关缓存：`internal/cache/`
- 初始化数据：`migrations/000002_migration_script_init_task_data.go`
- 前端任务页面：`web/app/routes/tasks.tsx`、`web/components/tasks/`

事件总线本身不能删除。话题、评论、点赞、收藏、关注和问答采纳事件还被通知、动态、索引等功能使用；应只删除任务侧订阅和不再需要的事件类型。

## 3. 明确范围

### 3.1 删除范围

- `TaskConfig`、`UserTaskEvent`、`UserTaskLog`
- `Badge`、`UserBadge`
- `LevelConfig`、`UserExpLog`
- `CheckIn`
- 用户字段 `score`、`exp`、`level`
- `UserScoreLog`、`AttachmentDownloadLog`
- 话题字段 `bountyScore`
- 附件字段 `downloadScore`
- 任务、签到、勋章、等级、经验、积分、用户任务日志相关 API
- 对应后台菜单、权限、前端页面、API 类型和国际化文案
- `LevelUpEvent`、`BadgeGrantEvent` 及其消息生成逻辑
- 登录态每日访问事件和 `DailyVisitCache`，因为它只服务每日登录任务
- 勋章图标资源和任务初始化种子数据

### 3.2 保留范围

- 话题、文章及其评论、点赞、收藏、关注和搜索
- 问答分类、问答发布、回答采纳，但不再包含悬赏积分
- 附件上传和下载，但下载不再扣费、不再记录购买关系
- 消息、举报、权限、用户管理等通用能力

## 5. 关键风险

### 数据破坏

删除任务日志、勋章、经验和签到表是不可逆操作。生产升级前必须完成备份，并明确是否需要导出归档文件。

### 迁移历史

任务初始化是历史迁移版本 2，问答悬赏配置是历史迁移版本 7。不能只删除源文件而不处理迁移注册，否则可能影响未完成旧迁移的数据库或导致新安装继续引用已删除模型和常量。建议保留版本号，将旧迁移改为空迁移，并在新版本迁移中统一清理旧数据。

### 权限残留

`PermissionService.SyncDefinitions` 主要负责新增和更新权限，不会自动删除代码中已经移除的权限。因此必须通过迁移主动清理增长类权限。

### API 兼容性

删除用户响应字段和 API 路由会影响旧版前端或第三方客户端。发布顺序应为：先发布前端，再发布后端，或在过渡版本中保留兼容返回。

### 内容自由化边界

问答发布必须移除积分余额校验、悬赏字段和悬赏扣除；回答采纳消息不再包含悬赏奖励，删除帖子时也不再退款。附件下载必须移除积分校验、购买记录和重复下载免扣费逻辑，统一按普通附件访问处理。历史数据若仍保留，展示和消息也不能继续暴露已删除的积分机制。

## 6. 完成标准

满足以下条件才算完成：

1. 新安装不会创建或初始化任务、签到、等级、经验、勋章相关功能。
2. 已有安装升级后，相关入口、API、权限和数据处理全部关闭或按数据策略清理。
3. 用户资料和消息不再产生等级、经验、勋章相关内容。
4. 话题、文章及其评论、互动、搜索、自由问答等保留功能不受影响。
5. 问答可以自由发布和回答采纳，不显示或处理悬赏积分。
6. 附件可以自由下载，不显示积分门槛、不扣费、不创建购买记录。
7. Go 测试、前端类型检查、Lint、SPA 构建和三种数据库迁移验证通过。
